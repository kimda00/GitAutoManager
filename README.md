# GitAutoManager

GitAutoManager는 Git 저장소 관리를 자동화하기 위한 C# 기반 콘솔 애플리케이션입니다.

## 기능
- Git 리포지토리 자동 초기화
- Git 커밋 및 푸시 자동화
- 기타 Git 관련 유틸리티 제공

## 개발 환경
- .NET Core 3.1
- C#

## 설치 및 실행 방법
1. 저장소 클론
    ```bash
    git clone https://github.com/your-username/GitAutoManager.git
    ```
2. 빌드
    ```bash
    dotnet build
    ```
3. 실행
    ```bash
    dotnet run --project GitAutoManager.csproj
    ```
